Windows Instructions
Preparation Phase
  1. Download and install OpenSSL for Windows:
    • Visit https://slproweb.com/products/Win32OpenSSL.html
    • Download "Win64 OpenSSL v3.x.x" (Light version is sufficient)
    • Install with default settings
  2. Add OpenSSL to your PATH:
    • Open Command Prompt as Administrator
    • Run: setx PATH "%PATH%;C:\Program Files\OpenSSL-Win64\bin"
    • Restart Command Prompt
  3. Verify installation: openssl version
Generation Phase
  1. Open Command Prompt and navigate to your project directory
  2. Create a directory for certificates:
    mkdir certs
    cd certs
  3. Generate private key:
    openssl genrsa -out server.key 2048
  4. Generate certificate signing request (CSR):
    openssl req -new -key server.key -out server.csr
    Note: You can press Enter for all fields except Common Name, which should be "localhost"
  5. Generate self-signed certificate:
    openssl x509 -req -days 365 -in server.csr -signkey server.key -out server.crt
  6. Verify certificate:
    openssl x509 -in server.crt -text -noout
Linux Instructions
Preparation Phase
  1. Install OpenSSL (if not already installed):
    # Ubuntu/Debian
    sudo apt update && sudo apt install openssl

    # CentOS/RHEL/Fedora
    sudo yum install openssl
    # or for newer versions
    sudo dnf install openssl
  2. Verify installation:
    openssl version
Generation Phase
  1. Open terminal and navigate to your project directory
  2. Create a directory for certificates:
    mkdir -p certs
    cd certs
  3. Generate private key:
    openssl genrsa -out server.key 2048
  4. Generate certificate signing request (CSR):
    openssl req -new -key server.key -out server.csr
    Note: You can press Enter for all fields except Common Name, which should be "localhost"
  5. Generate self-signed certificate:
    openssl x509 -req -days 365 -in server.csr -signkey server.key -out server.crt
  6. Set proper permissions:
    chmod 600 server.key
    chmod 644 server.crt
  7. Verify certificate:
    openssl x509 -in server.crt -text -noout
Certificate Location

After clicking "Generate Certificate", the files will be saved to:

./certs/server.crt - Certificate file
./certs/server.key - Private key file
Note: The certs/ directory is relative to your application's root directory.
Usage Instructions
  1. After generating the certificate, you will have two files:
    • server.key - Private key (keep this secure)
    • server.crt - Certificate file
  2. Configure your application to use these files for HTTPS
  3. The certificate is valid for 365 days
  4. For production use, consider using a certificate from a trusted Certificate Authority (CA)
