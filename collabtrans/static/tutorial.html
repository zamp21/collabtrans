Tutorial

Welcome to DocuTranslate! Follow these steps to translate your documents:

  1. Choose a workflow

    First, choose the translation workflow at the top of the configuration panel. Different workflows suit different file types:

    • Convert to Markdown then translate: For translating PDFs, Markdown, images, and more.
    • Plain text translation: For files like .txt.
    • JSON translation: Translate selected fields in .json files.
    • DOCX translation: For .docx files.
    • XLSX/CSV translation: For .xlsx spreadsheets and .csv files.
    • SRT subtitle translation: For .srt subtitle files.
    • EPUB translation: For .epub ebooks.
    • HTML translation: For .html files.
    New feature: The "Auto-select workflow" switch is enabled by default. Just upload your files and the system will pick a suitable workflow automatically.

  2. Configure parameters

    Complete the relevant settings based on the selected workflow. All settings are saved locally in your browser.

    • Parsing settings (only under "Convert to Markdown then translate" workflow):
      • Parsing engine: Choose an engine to convert your files (e.g., PDFs) to Markdown for translation. If your file is already Markdown, you can skip this.
      • Mineru Token: If you select the minerU engine, provide your token here.
    • TXT/DOCX/XLSX/SRT/EPUB/HTML options (shown in corresponding workflows):
      • Insertion mode: Define how the translation is placed in the document or subtitles: "replace", "append", or "prepend".
      • Separator: Used to separate source and target when using "append" or "prepend".
    • JSON path settings (only under "JSON translation"):
      • JSON paths to translate: Enter one JSONPath expression per line to specify which fields to translate.
      • Examples: $..description translates all values with the key "description". $.items[0].name translates the first item's name. $.* translates all strings.
    • Translation model:
      • Skip translation: When enabled, only parsing/format conversion runs, without calling AI for translation.
      • Select Platform/API URL/API Key/Model ID: Configure the AI translation service you want to use.
      • Refer to your platform's docs for model IDs. Prefer non-reasoning or hybrid reasoning models (with thinking disabled).
      • Generally, stronger instruction-following reduces errors and omissions.
    • Translation preferences:
      • Target language / Custom prompt / Glossary: Specify the target language, additional instructions, and glossary to ensure terminology consistency.
      • Thinking mode: Control whether hybrid reasoning models perform thinking. Currently supports GLM-4.5 (Zhipu), Qwen-3 (AliCloud), and Seed-1.6 (Volcengine). Disabling thinking is recommended.
      • Chunk size / Concurrency / Temperature: Usually keep defaults.
  3. Upload files

    In the task list on the right, click or drag your documents into the upload area.

  4. Start translation

    After selecting files, click the Start button at the bottom-right of the task card. Processing will begin and you can monitor progress in the log area.

  5. Review and download

    When translation completes, action buttons will appear under the task card:

    • Preview: Open a side panel to preview source vs. translation (for reference).
    • Download: Download translations in formats like PDF, DOCX, XLSX, HTML, Markdown, and more.
    • Attachments: Download any additional files generated during processing (e.g., glossary).
Tip: All settings are saved locally in your browser for next time.
